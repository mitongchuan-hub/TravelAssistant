# 用餐规划专项

2026-10-13新增`planning_meals_v1`，四例固定输入覆盖正常午晚餐、深夜已用餐与早离站自带早餐、预约已支付午餐与自带晚餐、三日七餐及全程餐饮额度。每例`review`列出人工核对项目。

沿用真实模型执行器，资料工具为统一受控不可用结果。用户已提供的预约时间、已付金额、自带餐和餐饮额度是需求事实；工具没有提供餐厅营业、菜单、排队、路线和价格依据。模型只能给区域或选择建议并保留未知，不能冒充已查证。使用独立内存Store，不向8000写测试消息，不运行后台展示转换。

```powershell
& E:\anaconda\envs\TravelAssistant\python.exe -X utf8 tests/performance/check_planning_prompt.py --dataset tests/datasets/planning_meals_v1/cases.json --output "$env:TEMP\planning-meals-new-run"
```

输出目录需为空。四例串行，固定本轮日期与旅行日期，模型请求、原文、需求、工具结果和源码分别留档。没有对历史规划提示词样本倒改结果。

机器检查仅覆盖任务状态、计划按授权变更及有效需求保持；不通过关键词计数自动判定餐次齐全，也不把任务成功写成用餐质量通过。人工逐日检查相关餐次、区域与前后衔接、已有安排、忌口与条件、人数/餐次/金额口径和总额度。首次失败保留，独立补测使用新目录。
