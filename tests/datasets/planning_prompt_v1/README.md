# 规划提示词独立验收集

`planning_prompt_v1` 是2026-10-13提示词重组后的专项，固定本轮日期为2026-10-13，旅行日期为2026-10-16起。六例覆盖七日六晚、已知雷雨、晚到早走、完整原话更新后生成、只记录撤销以及记录过敏后查询。

模型使用当前配置的真实服务；事实工具使用受控资料，Store只在内存中运行，不向8000写消息。不会生成后台展示卡片，验证范围是意图、需求更新、工具循环和规划正文。`rain`在数据中声明指定请求的合成结果，其他请求使用统一受控工具；不代表真实天气或外部服务可用性。

```powershell
& E:\anaconda\envs\TravelAssistant\python.exe -X utf8 tests/performance/check_planning_prompt.py --output "$env:TEMP\planning-prompt-new-run"
```

使用新空目录；`--cases PP-001 PP-002`可选择场景。按列表串行执行，生成源码指纹、配置、逐例原文、工具依据、模型轮次和机器检查，连续两次连接/超时失败后停止并保留已完成证据。首次失败和独立补测分别保存，不修改历史v1/v2成绩。

自动检查只验证计划是否按授权变更、需求字段、必要工具和任务状态。每例`review`列出人工评审项，需要对照原文与查询结果检查日期、抵离语义、预算合计、未知通勤、房间数、入住条件与天气备选。不能把机器检查通过写成完整行程质量通过。

SDK调用耗时包含网络、排队和生成；未比较旧提示词的同窗口配对样本，不计算提速比例。未测浏览器可见时间，未做展示转换验收，缺失token统计保持null。

实施与残余见[规划提示词改版](../../../docs/planning-prompt-redesign-20261013.md)。
