- DEL-003：次日07:30离站、早餐自备。路线使用明确标注的合成双向32/45分钟驾车及60/75分钟公交资料；这些值不是唐山实际交通事实。

输出目录必须是新的空目录，可用`--cases`单独选择。每次保留完整原文、源码快照、模型及工具调用、人工清单和业务库指纹；连续两次连接/超时错误后停止。`live_external`显式调用真实外部工具，其余场景采用受控资料。

任务成功与机器检查通过仅证明流程完成。当前不执行第二个模型的交付复核，也不从自然语言预算自动提取金额并计算上界。人工须核对交通方向与方式、酒店位置未知、时间衔接、全部相关餐次、逐餐与总预算、事实条件和简洁表达。首轮和后续独立复测分开保留，不能覆盖失败成绩。
