# 聊天界面改版验收

2026-10-13，按用户确认的方案完成第一版。沿用雾蓝配色，外框最大430px。此次变更是展示和交互层，不调用模型重新摘要，不修改既有消息、需求或行程内容。

## 可见变化

- 顶部固定显示返回、旅行名称和日期；旅行需求、清空聊天收进更多菜单。清空保留确认。
- 用户右侧蓝色气泡，助手左侧白色气泡；取消用户头像及逐条姓名/时间栏。助手连续回复只显示一组头像，时间间隔按已保存时刻显示，不补造日期。
- 助手正文安全渲染Markdown标题、段落、强调、列表和表格；HTML不执行、危险链接不可点击、图片不自动加载。用户消息保持纯文本和换行。
- 取消重复摘要卡。必要动作保留为轻量按钮；卡片中未在正文完整表达的bullet仍可展开“补充信息”，保存卡片不改。生成/修改动作指向当前行程，不把历史回复称为当前版本。
- 长回复默认显示开头完整段落，可展开全文并收起；不截断句子、不生成另一份模型摘要。单一长段落保持全文可读。
- 自动增高的多行输入，最多约5行；Enter在桌面发送、Shift+Enter换行，触屏Enter换行，中文输入法组合事件不发送。空消息不可发送，草稿在当前浏览器会话恢复。
- 等待反馈在助手的小气泡内。仅使用真实的“正在整理回复”，没有模拟阶段、百分比或逐字输出。等待模型时输入可用，补充消息沿用后端最新消息优先规则。
- 消息列表独立滚动。底部阅读时跟随新消息，翻看历史时保留消息锚点并提示“有新回复”；展开状态不因轮询消失。
- 输入与导航放在视口底部；visualViewport变化时调整可用高度，键盘明显占用高度时收起底导航。未声称桌面浏览器自动化代替实体手机键盘验收。
