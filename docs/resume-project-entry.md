# 个人项目

## TravelAssistant｜AI 同城游玩规划助手

**2026 年 10 月｜独立完成**

**技术栈：** Python · FastAPI · Uvicorn · Jinja2 · SQLite · OpenAI 兼容模型 API · MCP · 高德地图 Web 服务 / MCP · Open-Meteo · pytest

**项目介绍：**

从 0 到 1 独立搭建面向同城出行的 AI 旅行规划 Web 产品。用户确认住宿地点、出行日期和游玩天数后，可通过对话整理偏好，查询地点、餐饮、市内交通和天气，生成并调整从住宿出发、最终返回住宿的多日游玩路线。

**主要工作：**

- **产品闭环：** 独立完成认证、住宿地图匹配、必填日期/天数、对话式需求整理、路线生成、行程展示、局部调整、SQLite 持久化和失败重试，形成从创建旅行到生成/修改行程的完整闭环。
- **Agent 执行架构：** 设计主 Agent 编排需求整理、资料查询、行程规划和行程修改能力；通过 `TaskExecutionRuntime` 实现有界工具循环，通过 `TurnWorkspace` 汇总候选、`TurnCommit` 原子提交，结合 request ID、版本校验和旧结果失效机制，避免重复请求及过期结果覆盖当前行程。
- **可靠性与评测：** 将业务边界、未知事实不补造、查询失败可恢复、正文与路线卡片解耦等规则纳入提示词和运行时；构建覆盖 12 类其他领域、混合请求、多轮诱导和提示词注入的 80 条评测集，真实评测中 70 条越界/混合请求未观察到其他领域实质作答，10 条合法对照未被误拒，并定位无授权工具调用和状态反馈问题。
