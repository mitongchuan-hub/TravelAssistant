日期：2026-10-12。已加载本地服务。后续已根据用户反馈恢复430px统一宽度，并完成[重复内容修复](itinerary-repetition-20261012.md)：摘要/概览合并，渲染副本去掉完全重复文本；新截图和最终服务状态见该记录。范围为行程页的阅读层次、卡片布局、日期导航、响应式与展开交互；行程原文、模型提取和后端任务逻辑保持原有行为。

## 页面调整

- 摘要去掉两次重复的行程状态，改为天数、同行人数和预算，状态独立显示。数值来自已保存方案的需求快照；卡片尚未完成时使用对应天数依据。
- 阅读顺序为整体安排、行前信息、每日行程、核实/提醒、原文与修改。长预算和住宿通过原生details展开，衣物默认展开，全部内容仍在DOM中，支持键盘。
- 天气用按日期分组的卡片，气温、降水、查询时间和预报备注分开；衣物与住宿有独立区域。
- 每日活动沿时间轴排列，类别颜色与文字并用；安排说明、地点、时长和费用分区，备注保留可见提醒，不截断预约、忌口、未知或预算限定。
- 日期导航吸顶、随滚动高亮，七日可横向浏览；点击时避开导航栏，窄屏切换时自动测量高度。初始化同时适用于首次加载和异步插入卡片，替换后清理旧监听。
- 手机为单列卡片。根据用户反馈已撤销桌面760px扩宽，行程页与底部导航恢复统一的430px最大宽度，较窄屏幕仍适应窗口。旧格式行程继续支持。
- “调整此项”、全文阅读、修改、确认、卡片重试保留；遵从减少动态效果偏好。静态资源版本已更新，刷新可获取新样式。

## 验证

- 61项相关自动测试通过，覆盖工作流、异步卡片与页面交付。
- 新增display_cards_browser：使用固定评测的当天、三日、七日内容及独立内存Store，在320/390/430/768/1280宽度验证无横向溢出。逐项确认描述、准备、天气、费用和提醒字段仍存在，预算/住宿键盘展开可用；日期跳转/高亮、调整按钮和原文入口可用。天气恶意字符串被转义，无浏览器运行错误。
- async_display_browser通过：阻塞卡片时先读原文；迟到卡片不丢草稿、选区或阅读位置；失败后只重试卡片。

- 旧itinerary_browser通过：四种宽度的旧日期导航、修改弹层、草稿、网络失败和单次提交兼容。
- JS语法和git diff --check通过。未调用真实模型做本次UI测试，不把浏览器受控结果当模型质量或真实速度。
