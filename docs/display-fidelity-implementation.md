## 本次修改

`app/prompts/agents/display.txt`明确逐项提取规则，`app/schemas/itinerary-display-v1.json`同步字段说明；JSON字段、版本、前后台交付与预算规则保持兼容。

- 时间表达必须保留左右、最晚、建议等限定，原文没有的时刻不根据相邻活动补齐。
- 时长仅摘录原文明示内容，禁止用起止时刻相减生成新时长，不把候车缓冲当交通耗时。
- 按主要内容区分活动/餐饮/交通/住宿/休息，明确散步与午餐不能统一标成transport。
- 衣物只放衣物和携带装备，扫描开头及天气段落；餐厅、酒店和待核实清单不得错放clothing。
- 住宿保留候选、预算、房态与价格待确认。概览必须完整，预算保留人数、总额、覆盖范围与非报价措辞。
- 保留预约、忌口/过敏、雨天替代、二选一及未知条件；禁止notes内嵌JSON和options_detail等技术标签。

这些是模型提取规则，不是程序已具备全面语义验证。当前本地强校验仍主要负责结构、日期与原文绑定；没有用关键词猜测修改用户行程或自动掩盖模型错误。
