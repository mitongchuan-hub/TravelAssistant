# 手机端第二组静态设计记录

## Overview

本轮获准交付 **10 张手机单款图、1 张总览图与 AB 对照页**。全部沿用同一组杭州旅行合成内容，研究聊天工作区的视觉构造，不覆盖创建住宿、地图匹配、聊天、攻略与下载的完整流程，也不是 10 套正式上线主题。本文件仅描述本目录，不替代正式的 `docs/DESIGN.md`，不授权修改现有页面排版。

相较第一轮的大标题、纸感／贴纸装饰、卡片与阴影，第二轮把空间还给对话：旅行依据收为一行，减少嵌套容器，用时间条目、文档、日期锚点、文本清单、整片底色和标准行组区分方向；保留轻松、圆润的感觉，不是仅换配色。第一轮 10 款完整保留，AB 同号仅方便浏览，不表示逐一替代或已选定新方案。

参考研究见 [RESEARCH.md](./RESEARCH.md)：学习 Memos 的内容层级、Blinko 的移动记录组织、NextChat 的阅读／输入边界与 Vant 的紧凑尺度。实现独立编写，不复制参考项目品牌、图像或源码，也不据此声称实现了它们的动态交互。

## Colors

强调色用于攻略入口、路线、保存提示与发送外观；浅底区分背景、用户消息和分组，深色承载正文。下表按 `styles.css` 的最终有效值记录，B06 已计入末尾的对比度调整。

| 编号／方向 | 构造差异 | 主底／正文／强调／柔和底 |
| --- | --- | --- |
| B01 亲切通讯录式 | 完整气泡，助手回复与撤销随头像缩进，依据单行呈现 | 抹茶：`#f3f5f0`／`#2c3931`／`#3c6852`／`#e2ece0` |
| B02 清爽对话式 | 用户保留气泡，助手开放正文；圆头像、胶囊输入与选中态 | 樱花：`#fffafb`／`#45383d`／`#954d66`／`#f6e4eb` |
| B03 旅行短记式 | 日期标题与连续时间轴，时间归属条目，不堆叠气泡 | 杏黄：`#fffdf6`／`#493f2c`／`#876327`／`#f1e6c8` |
| B04 随身笔记式 | 用户原文后接文档式回复，标题、正文和结果页脚分层 | 浅紫：`#f1eff6`／`#42394e`／`#70558b`／`#e8e0f1` |
| B05 日程便笺式 | 小日期牌与当天说明并排，多日日期成为阅读锚点 | 湖蓝：`#f7fbfc`／`#2b424b`／`#336e82`／`#e0eef2` |
| B06 想法清单式 | 顶部紧凑文本想法，开放回复，结果与撤销集中浅色区 | 蜜桃：`#fff9f5`／`#513d34`／`#8b4c34`／`#f5e3d7` |
| B07 轻量工具式 | 弱化装饰，回复外独立工具带统一保存、攻略与撤销 | 青绿：`#fafcfb`／`#273e38`／`#326c59`／`#e1eee7` |
| B08 柔和分区式 | 整片底色分隔提问与回答，不再套多层卡片 | 淡紫：`#f8f6fb`／`#443a53`／`#72588c`／`#e9e1f2` |
| B09 温暖阅读式 | 连续正文、大一档回复标题，日期与作者退为旁注 | 奶咖：`#f9f5ee`／`#493e33`／`#7a5940`／`#eee2d1` |
| B10 圆润原生式 | 标准行式信息，白底路线摘要，保存与撤销组成轻圆角行组 | 雾蓝：`#f0f3f7`／`#304156`／`#386490`／`#e1eaf4` |

## Typography

使用本地系统字体 `Microsoft YaHei UI`、`Microsoft YaHei`、`sans-serif`，不加载外部字体。常规正文 14px、行高约 1.85—1.9，旅行标题 17px；B02 首段 17px、B03 日期 22px、B09 回复标题 21px，承担不同阅读层级。元信息约 9—12px，属于本轮观察值，不是正式产品的小字可读性标准。

## Layout

单款基准 **390 × 844**，最大宽度 430px、高度 `100dvh`、最小高度 740px。纵向排列状态栏、标题、旅行依据、独立可滚动内容区、输入外观与想法／聊天底栏；常规内容左右留白 20px，B08 以通栏底色自行分区。

总览宽屏五列，1050px 以下两列、500px 以下单列；缩略 iframe 以 390 × 844 为内部尺寸按宽度缩放。AB 页左右各一款，同样缩放，并非两套真实产品同时运行。

### 看图与 AB 对照

- 打开 [index.html](./index.html) 看总览，点击款式打开单款；地址加 `?style=1` 至 `?style=10` 对应 B01—B10。
- 图片在 `images/`：[B01.png](./images/B01.png)—[B10.png](./images/B10.png) 为手机图，[overview.png](./images/overview.png) 为总览，[comparison.png](./images/comparison.png) 为默认首组 AB 截图。
- 打开 [compare.html](./compare.html)，下拉选择 01—10：左侧为第一轮 A 稿，右侧为第二轮 B 稿。要看其余配对需切换页面选择，静态 `comparison.png` 不含全部配对。
- 比较信息密度、阅读顺序、容器边界和操作归属，不只比较色相；可从页面返回[第一轮总览](../mobile-styles/index.html)。

## Elevation & Depth

手机内部主要靠浅色分区、白底和细分隔线建立层级，不用第一轮的新拟物或装饰性浮起效果。总览缩略图有轻阴影和描边，仅用于看稿外壳，不是业务卡片规范。

## Shapes

保留轻圆角而非统一大卡片：常规用户气泡为不对称 17px 圆角；输入外观约 11—24px；文档和结果组约 12—14px。头像、发送键和底栏的具体形状随构造变化。内联 SVG 承担图标，不引入图标字体或远程素材。

## Components

| 真实产品能力 | 本稿对应与不可操作边界 |
| --- | --- |
| 住宿表单创建、地图匹配 | 标题日期与「住宿已匹配」仅合成背景；无表单、查询或匹配结果 |
| 聊天生成、调整、确认 | 固定一问一答、路线摘要、「行程已保存／草案」；不调用模型，不保存或确认 |
| 输入与发送 | 输入区是 `span` 文本，不是输入框；发送按钮不发送 |
| 想法管理 | 底栏入口与 B06 三条想法仅展示；无切页、编辑、勾选采纳；「少走路」等不是本稿读取到的用户事实 |
| 攻略覆盖预览、打开与 HTML 下载 | 顶部攻略和回复内查看攻略只有外观；本稿没有攻略层、下载按钮、文件生成或下载行为 |
| 最近三次实际 Agent 修改撤销 | 固定显示「可撤销 1 步」；无历史、撤销状态或重做，也不能恢复失败任务 |

手机内返回、攻略、查看攻略、撤销、发送与底栏均不执行业务。可用交互仅为总览链接、AB 下拉、链接跳转及页面／内容区滚动；按压或焦点样式不代表功能可用。全部无业务请求、无后端连接，不增加预订、支付、社区、实时地图、PDF 或多版本历史。

**指南隔离边界：**正式攻略 HTML 及其 iframe 沙箱由正式后端生成；本目录的 iframe 仅装载静态看稿，不是正式指南实现。`住处 → 西湖 → 喝茶 → 住处` 是静态路线示意，不能因正式产品存在沙箱或地图能力，就说本示意路线已经实际查询、核实或可执行。时间、日期、保存状态和核实提醒均为测试展示。

## Do's and Don'ts

### 检查事实与未完成项

- 当前自动报告：390 × 844 全 10 款无横向溢出、检测范围内无文本截断、内容区无纵向溢出；375 × 812 全部无横向溢出，B01／B04／B05／B06／B09 内容区可纵向滚动。
- 关键文本对比度抽检均 **≥ 4.5**。`verify.cjs` 检查指定选择器的文字与背景，不是全部元素、全部状态的完整无障碍认证；不能据此宣称所有触点、键盘体验或阅读体验均已达标。
- 独立视觉 review 最终为 **ship：可交付静态选款，无阻断项**，不代表生产上线或用户必定满意。THESIS／OWN-WORLD／STORY／FIRST VIEWPORT／FORM 均符合本次范围。保留意见：B02／B07／B10 是相邻方向，B04／B09 均偏阅读；B09 标题与首句有轻微语义重复。没有把十款宣称为十种完全不同架构。自动几何检查与对比度抽检不等同完整产品验收。
- 已有渲染前后记录显示第一轮 hash 完全一致；`render.cjs` 对照范围为第一轮 `index.html`、`render.cjs`、`DESIGN.md` 与 `images/` 文件，不扩展为整个仓库不变的证明。

### 复现

在项目根目录执行（需已有 `frontend/node_modules/@playwright/test` 和本机 Google Chrome）：

```sh
node docs/design-previews/mobile-styles-v2/render.cjs
node docs/design-previews/mobile-styles-v2/verify.cjs
```

前端依赖缺失时，先在 `frontend/` 执行 `npm ci`。无需启动前后端，不调用业务接口，也无需另下载 Playwright Chromium；脚本使用 `channel: 'chrome'` 和本地文件访问。

`render.cjs` 会覆盖本目录 `images/B01.png`—`B10.png`、`overview.png`、`comparison.png`：手机截图 390 × 844、像素比 2，总览视口 1800 × 1900，AB 视口 1020 × 1300，后两者为整页截图；另在 375 × 812 检查窄屏，控制台输出溢出、截断、页面错误与原稿 hash 对照。内容区纵向滚动本身不触发脚本失败。`verify.cjs` 在 390 × 844 输出内容区隐藏像素数与低对比度抽检列表，需阅读输出，不能只凭退出码判断对比度通过。

本次文档交付不重渲染或改写图片；以上结果来自当前已有报告。后续选定视觉方向仍需单独授权、接入真实交互并重新验收，不能把静态图直接当作正式功能或完整流程已经完成。
