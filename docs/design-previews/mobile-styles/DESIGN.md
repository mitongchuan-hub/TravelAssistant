# 手机端静态视觉研究

## 范围与边界

本目录用同一组杭州旅行示例内容，对比 10 款手机端视觉方向，基准画幅为 **390 × 844**。研究范围是聊天工作区的配色、圆角、卡片、气泡、装饰与底部导航，不是 10 个已完成的产品主题，也不是住宿填写、地图匹配、聊天、攻略、下载的完整流程。

正式页面、后端和正式设计系统未因本预览修改；本记录仅适用于本目录，不替代正式 `docs/DESIGN.md`。

## 真实功能与预览对应

| 真实产品能力 | 本预览呈现 | 覆盖边界 |
| --- | --- | --- |
| 聊天表达想法、生成与调整行程 | 一条用户消息、助手回复、路线摘要、发送外观 | 固定示例，不可输入或发送，不生成、不保存 |
| 想法记录与查看 | 底部「想法」入口 | 仅按钮外观，没有想法页或切换行为 |
| 攻略覆盖式预览 | 顶部「攻略」、回复内「查看攻略」、草案状态 | 未实现预览层、独立 HTML 或打开网页 |
| 撤销上次修改 | 「撤销上次修改 · 可撤销 1 步」 | 固定文案，没有撤销历史或状态变更 |
| 攻略 HTML 下载 | 总览页脚提及真实产品能力 | **下载属于真实攻略能力，本预览未实现下载按钮、文件生成或下载行为** |
| 住宿填写与地图匹配 | 「住宿已匹配」、交通与偏好标签 | 仅背景示例，未实现表单、地图查询或匹配 |

## 示例与交互说明

- 「杭州慢慢逛」、11 月 14—15 日、住宿已匹配、路线、时间及「行程已保存」均为示例，不代表真实查询或持久化结果。
- 页面已有「示例对话」「静态设计 · 测试展示，非真实行程」及总览测试说明；交通估算与预约核实提示也是展示文案。
- **无业务请求、无后端连接**，不调用模型、地图或行程接口。资源来自本地 HTML、内联样式与 SVG。
- 手机画面中的返回、攻略、查看攻略、撤销、发送、想法和聊天均不可执行真实业务；输入区域只是文本，不是输入框。
- 可用的交互仅用于看稿：总览中的款式链接打开单款预览，页面及内容区域可滚动。

## 查看与复现

在文件管理器中打开本目录的 [index.html](./index.html)，浏览器会展示 10 款总览；点击款式标题可打开原尺寸单款。也可在地址后加 `?style=1` 至 `?style=10`。

已有图片位于 `images/`：`01.png`—`10.png` 按上表编号对应单款，[overview.png](./images/overview.png) 为总览，均可直接用图片查看器打开。

在项目根目录执行：

```sh
node docs/design-previews/mobile-styles/render.cjs
```

脚本使用 **frontend 现有的 `@playwright/test` 依赖**和本机已安装的 **Google Chrome**（`channel: 'chrome'`），不启动前后端服务，也无需另下 Playwright Chromium。若前端依赖尚未安装，先在 `frontend/` 执行 `npm ci`。

复现会覆盖本目录 `images/01.png`—`10.png` 与 `overview.png`：单款以 390 × 844、2 倍像素比截图；总览以 1800 × 1900 视口整页截图。脚本另在 375 × 812 视口检查水平溢出，并向控制台输出溢出与文字裁切检查信息；这不是正式页面的完整可用性或端到端测试。
