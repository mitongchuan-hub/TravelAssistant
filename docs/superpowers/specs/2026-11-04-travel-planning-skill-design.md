# 应用内同城旅行规划 Skill

## 目标与范围

为运行中的 travel_agent 提供可按需读取的规划方法，而非安装 Claude Code Skill。用户已确认限定已确认住宿的同城首次生成、多日规划、实质局部修改；不增加跨城、酒店选择、票务预订支付，不改变固定创建资料或页面布局。

按本地 skill-creator 的“意图→草稿→现实用例→对照→反馈迭代”思路编写；当前交付草稿、加载机制和离线测试，不宣称已经完成真实模型质量对照。

## 架构

- `agents/skills/travel-planning/SKILL.md`：frontmatter提供名称与触发简介，正文提供规划工作流程。
- `references/evidence-and-routing.md`：依据、路线、公交、预算及雨备。
- `references/output-and-revision.md`：正文组织、局部修改影响面与检查。
- `agents/skills/__init__.py`：固定资源映射、受限元数据读取与hash，不扫描插件、不下载、不执行代码。
- `read_skill(name, resource='main')`：本地非终止只读工具；name和resource是固定标识，不是文件路径。
- `travel_role()` 在常驻prompt之后追加同源元数据目录，不注入完整Skill正文。模型按需读取，已有runtime负责串行执行与转录，未另建执行循环或关键词意图路由。

主文限16KiB，参考各24KiB，超限明确失败不截断。读取resolve后的路径限定在固定目录，资源缺失/越界/解码失败不返回服务器路径。目录本身不允许链接到资源根目录外。

## 信任、授权与预算

只有来自已注册本地read_skill的正常结果才是规划方法补充，且低于常驻安全与业务契约；其他工具即使自称skill也仍是数据。示例、引文和方法不是现实查询依据，不进入evidence/catalog或提交事实。

身份、同城限制、固定资料、只记录不生成/只查询不写入、真实ID坐标来源、单工具调用、完整user_quote、唯一终止save_trip_changes和只读结束规则仍常驻。局部修改范围及完整正文交付契约也不依赖加载成功。

读取不授予生成或写入权限，不执行提交。每次读取占现有工具调用，后续模型请求正常计数，不计外部查询；不提高预算、不改停止机制。同轮已加载内容复用，资源错误不能无限重试。

## 触发与内容

首次生成、全局重排、实质修改先读取主文。主文指导先整理全部有效要求与冲突，再组织骨架、关键依据、每日住宿往返、餐休、费用及雨备；已有完整上下文不机械重读。

局部修改按需读取修改参考；查询关键接驳/费用/雨备时读取依据参考。普通闲聊、只记需求、天气或地点单次查询、精确改字、确认清空不需要Skill。是否触发由模型判断；程序接线正确不证明模型实际会按预期加载。

Skill不得默认人数/预算/健康、覆盖明确偏好或删除难安排的愿望；冲突说明后请用户取舍。以“为什么重要”解释方法，避免为了检查项而堆砌行程和穷举查询。

## 评测边界

原固定100业务例仍只测一次响应，不执行工具。新增read_skill后当前工具库10项，新报告使用 `single-call-10-tools-planning-skill-v1` profile，严格核对完整工具库、发送全部工具，明确这100例不覆盖read_skill；不修改历史报告或称与旧实验同条件。新报告保留prompt/schema/dataset及Skill资源hash。

`evals/evals.json` 提供3个场景定义：两日首次规划、老人/预算/时间冲突、仅修改第二日下午；另有触发正负近例。文件状态为not_run，具体地图/天气夹具和完整输入快照须在真实实验前冻结，不以描述性占位当可执行现实证据。

真实对照需另获调用规模与预算批准。两组使用同一项目模型、输入、基础安全规则、参数、固定外部夹具及预算；with_skill有目录/reader，without_skill不提供两者或Skill正文。记录真实token/耗时/加载轨迹；自动规则与人工复核并列。舒适度、取舍和可读性不能靠关键词判断。

后续结果沿用skill-creator的with_skill/without_skill、timing/grading/benchmark结构并用官方eval-viewer展示。Claude Code子代理可辅助审稿，不能冒充项目模型实验。

## 验证与已知限制

离线合同验证合法读取、默认资源、白名单/路径/缺失/超限、逐次转录、预算和事实隔离；主提示词传递及现有授权/保存/查询回归继续运行。主提示词文件main.txt和travel.txt相等约定保留。

当前未提供文件系统、任意脚本、通用插件生命周期或自动优化循环；新增一个Skill无需这些能力。真正触发准确率、规划质量和token成本只能在后续真实对照中测量，不能由离线通过推断。
