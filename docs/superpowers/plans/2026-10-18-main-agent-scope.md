# 主 Agent 业务范围实施范围

本次仅落实职责设计中的业务受理边界：按事项判断同城业务、限制直接回答、混合请求保留合法部分、专业摘要不透传越界内容、查询失败不扩大职责。

实施：修改 main、requirements、research、planning、revision 提示词；保留 display 的原文提取职责。无需新增分类器、模型调用或关键词路由；直接文本和结构化回复共用主系统提示词。

验证：先通过真实主运行时复现数学与翻译越界，再运行真实主模型评测。专业能力替换为明确 unavailable，隔离外部服务与业务写入，测试主控分发及失败回退。分别记录直接文本和 finish_turn，逐条人工评审自然语言。离线测试仅验证评测器确实走通两种终止合同，不作为语义通过证据。

本次不调整追问保留、提交回执或保存状态规则。运行时继续验证既有引用及写入合同；业务范围仍由模型依据提示词判断，不宣称确定性阻止所有越界。
