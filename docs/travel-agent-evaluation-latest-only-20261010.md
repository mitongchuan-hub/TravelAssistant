## 未通过、歧义与覆盖限制

### TA-010：国外预算的币种说明不完整

正文按东京当地时间、3日2晚、20:00抵达和09:00离开正确安排，酒店/交通/天气未知明确保留，没有捏造班次或实时汇率。但预算写“6000元”“每晚1600元”而未明确人民币计价或注明汇率未知，不满足该例严格币种检查。

这是限定说明缺失：所有金额表达为预算上限，未提供日元报价或虚构换算。确认时间和住宿夜数正确不等于所有检查通过。

### TA-002/012：评测前提不足，单列

TA-002实际保存已输入的城市、抵离日期时间、人数、预算范围及西湖/忌口。用户没有提供离开地点，模型正确留空并说明，不能为了达到“抵离地点完整”检查补造杭州东站。

TA-012实际记录100总预算及一晚独立双床要求，暂停规划、询问取舍，未擅自取消住宿或增预算。但没有获取300元报价，因此未完成严格的报价比较。该报价并未预先提供，酒店关键词又可能先被车站POI匹配，覆盖住宿报价分支。按既有根因排查单列评测问题，不能算通过，也不能等同于生成了错误低价方案；旧报告统计保留。

### TA-018：本次回答满足检查，工具组合查询未被覆盖

严重花生过敏实际落档并保留不吃辣。回复提供条件式杭州午餐类型/菜品建议，明确菜名不证明安全，要求核实成分及交叉接触，无法确认则不就餐。本次满足业务检查。
