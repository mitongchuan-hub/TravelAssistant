# 规划提示词改版证据

真实模型是当前配置的Lab Qwen27B，规划默认medium；外部事实为合成资料，Store独立内存，后台展示不执行，不向8000写消息。日期与输入在dataset.json固定，串行单次运行；此专项不修改历史v1/v2成绩，不代表真实天气或地图服务可用性。

- `before/`：修改前两份提示词和工具配置。
- `first/`：首轮六例结果、原文、配置、源码指纹与人工评审。五例机器通过，PP-004漏存pace；四例规划正文有语义残余。
- `second/`：独立复测六例，首轮结果不覆盖。五例机器通过，PP-004漏存pace；返程、房间数、星期和重复更新问题保留。
- `final/`：最终六例，同样五例机器通过，PP-004漏存pace；最终人工评审为`not_fully_passed`。PP-005只记录撤销及预算变更，PP-006记录过敏后查询通过核心授权/需求检查。
- `automated-final.log`：最终585项自动测试通过，50.66秒；`targeted.log`：61项针对性回归通过。pip check正常。
- `deployment/`：本次新业务快照，15旅行/88消息，无活跃任务；加载前后业务对象逻辑hash一致。

各轮机器检查不验收自然语言事实。原文中的反向交通耗时复用、每日餐饮建议与全程额度冲突、未知接驳下的早离站窗口，以及PP-004虚构温度/距离/线路/免费开放和默认房间数均在manual-review.json中记录。未更改输出使其通过，未把任务成功写成语义成功。

模型调用时长仅用于定位轮次，不计算因果提速。没有与旧提示词同窗口配对，未测首token、浏览器可见时刻或后台卡片质量。关键剩余问题需要确定性输入、通用校验及模型能力配合，不能靠继续堆提示词保证。
