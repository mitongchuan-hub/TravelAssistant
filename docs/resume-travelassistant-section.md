# 项目经历

个人项目                       TravelAssistant 同城游玩规划 Agent                              2026 年 10 月-至今

项目链接：https://github.com/mitongchuan-hub/TravelAssistant

技术栈：Python · FastAPI · Jinja2 · SQLite · OpenAI 兼容模型 API · MCP · 高德地图 Web 服务 · Open-Meteo · pytest

项目介绍：从 0 到 1 独立搭建面向同城出行场景的 AI 行程规划 Web 产品。用户确认住宿地点、出行日期和游玩天数后，系统通过对话整理游玩偏好，调用地图、天气等工具查询实时信息，生成从住宿出发并返回住宿的多日游玩路线，并支持对行程进行局部调整。

主要工作：
1. 产品闭环：独立完成用户认证、住宿地点地图匹配、日期与天数校验、对话式需求整理、路线生成、行程展示、局部调整、SQLite 持久化及失败重试，形成完整的行程规划业务闭环
2. Agent 编排与任务一致性：将需求整理、地点/天气查询、路线生成和方案修改拆分为可组合能力，由主 Agent 统一调度并限制工具调用边界；设计任务状态和结果校验机制，确保用户连续修改行程时始终保留最新一次结果，避免重复执行和旧结果覆盖新方案
3. 业务边界与可靠性：将同城游玩范围、未知事实不补造、工具失败可恢复等规则同时纳入提示词和运行时；构建覆盖 12 类越界领域、多轮诱导和提示词注入的 80 条评测集，实际评测中 70 条越界/混合请求未观察到其他领域实质作答，10 条合法对照未被误拒
