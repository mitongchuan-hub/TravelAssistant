## 分类资料

- `archive/`：旧框架提案、旧运行循环解释与研究记录；不能当成当前代码说明。
- `learning/`：学习计划；旧代码路径和旧框架示例可能已失效。
- `career/`：简历、面试材料；包含历史阶段内容，不作为当前能力或指标证明。
- 其他既有专题目录保留其原用途；日期化方案和评测只描述当时状态。

文档归档不是删除功能，也不代表历史测试成绩仍然有效。启动与验证的唯一入口说明见 [项目 README](../README.md)。
